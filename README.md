A coin shower is a common feature in casino games, especially during big win animations. 
It's a burst of coins that originates from the center of the screen, and rains down.

The example uses the PIXI rendering library. 
To make the test easy to run and easy to modify, everything is delivered in a single file instead of a complete frontend project. 

PIXI documentation can be found here:

https://pixijs.download/v8.1.8/docs/index.html
